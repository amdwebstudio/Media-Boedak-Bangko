Cara Memasang dan Menjalankan File HTML

  1. Salin seluruh kode dari file editor di sebelah kanan.
  2. Buat file baru di komputer menggunakan Notepad atau Code Editor (VS Code).
  3. Simpan file tersebut dengan nama persis index.html.
  4. Klik dua kali pada file index.html untuk membukanya langsung di browser (Chrome/Edge/Firefox). Selesai!
